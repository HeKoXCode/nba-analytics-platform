# Raw data source and scope

Original shared folder: [Google Drive download](https://drive.google.com/drive/folders/1J_-mhQ0fBr2I8qH2wtx1iOs0-8hSklF6?usp=drive_link)

## Verified scope

- The linked source folder was approximately **2.31 GB** when audited on 10/08/2026.
- This repository processes only six committed CSV inputs totaling **30,638,984 bytes** (30.64 MB decimal / 29.22 MiB).
- The external folder size may change independently of this repository.

The source folder and the ETL subset are therefore different scopes. The repository must not describe the full external folder as data actually processed.

## Reproduction and licensing note

Access to the shared folder, its future availability and its redistribution terms are controlled outside this repository. Before reusing or redistributing the data, verify the source license and NBA-related rights. The committed CSV subset is included as project evidence; it is not presented as an independently licensed public dataset.
