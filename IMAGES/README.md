# Dashboard images — edition notice and capture protocol

## Current English edition

Start with [the six current English previews](powerbi_english/README.md) or the [native report PDF](../DOCS/media/technical/nba_english_report_native_hq.pdf). These show the approved English PBIT at baseline; the gallery below belongs to the preceding Spanish edition.

The four PNGs in [`powerbi_storytelling/`](powerbi_storytelling/) document the **earlier Spanish dashboard** and are retained as historical evidence. For the current English report, use the [six-page gallery](powerbi_english/README.md), [native PDF](../DOCS/media/technical/nba_english_report_native_hq.pdf), [PBIT build guide](../CODE/Dashboard%20-%20POWERBI/README.md) and [dated verification](../DOCS/english_release_verification.md).

For a future English gallery, capture **each of the six pages** only after opening the pinned English template against a loaded, isolated SQL database and confirming baseline filters. Record the PBIT hash, database, refresh date, Desktop version and filters. Keep the cursor outside the canvas; remove editor warnings, spinners, selection outlines and personal connection details. Reconcile visible numbers with [`30_reconciliation.sql`](../CODE/SQL/30_reconciliation.sql) and the [English snapshot](../evidence/NBA-English-2026-09-29/insight_snapshot.json). Capture readable desktop images first, then make separate phone-width crops for social posts; a crop is **not** a native mobile Power BI layout.
